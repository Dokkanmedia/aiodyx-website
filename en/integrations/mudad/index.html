Your WPS file comes straight from Odoo payroll

Mudad is the Saudi wage protection (WPS) platform. It checks that private-sector salaries are paid on time and in the agreed amounts. AIODYX links approved Odoo payroll to the WPS file in the format Mudad requires.

Book a free consultationPackages

Why this integration matters

Building the payroll file by hand from a spreadsheet means retyping figures and errors in IBANs and ID numbers. Any gap between what was paid and the contract shows up as a wage protection violation.

What happens automatically

  • WPS file generated from payroll once approved
  • IBAN and ID checks for every employee before export
  • Basic pay, allowances and deductions broken down as in the contract
  • File ready for submission to Mudad with no retyping
  • Paid amounts reconciled with the bank statement

How we connect it

  1. 1Approve payroll inside the system
  2. 2Generate the WPS file
  3. 3Submit to Mudad
  4. 4Reconcile payments with the bank

What we need from you

  • The establishment's Mudad account with upload rights
  • Odoo Payroll enabled with employee contracts
  • IBAN and national ID or iqama number for each employee
  • The payroll file format used by your bank

Frequently asked questions

Does payroll calculation change?

No. Payroll runs as before, and the file is built only from the approved result.

What if an employee's IBAN is missing?

The system blocks the export and lists employees with missing data so you fix them first.

Does it cover several establishments?

Yes. A separate file is generated per establishment or CR, based on your company setup in Odoo.

How is reconciliation done after payment?

The bank statement is imported into Odoo and transfers are matched to payroll entries, so any failed transfer stands out.
